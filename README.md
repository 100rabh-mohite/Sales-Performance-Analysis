# Sales Performance Analysis Project

## Overview
This project analyzes retail sales data using SQL, Python Pandas, and Power BI.

## Tools Used
- MySQL
- Python
- Pandas
- Power BI

## Features
- Revenue trend analysis
- Product performance analysis
- Customer segmentation
- Regional sales heatmap
- KPI dashboard

## Key Insights
- Peak sales hours identified
- Top-selling products analyzed
- Repeat customers detected
- Regional sales comparison performed
